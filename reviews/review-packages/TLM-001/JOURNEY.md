# Journey Digest

Canonical sources: `journeys/teacher/`.

## Coverage checklist

| Horizon | Covered |
|---------|---------|
| Before school (plan, materials, travel) | Yes |
| Morning assembly | Yes |
| Classes / doubts / homework / attendance | Yes |
| Assessments | Yes |
| Communication | Yes |
| Unexpected events | Yes |
| After school (evaluation, reports, parents, tomorrow, PD) | Yes |
| Weekly (tests, meetings, planning) | Yes |
| Monthly (PTM, reports, exam prep) | Yes |
| Academic year (planning, teaching, exams, results, admissions, holidays) | Yes |

## Highest-leverage moments

1. Night-before / morning prep pack  
2. In-period understanding checks  
3. Post-assessment weak-student shortlist  
4. Parent message drafting under approval  
5. Lost-period recovery / re-pacing  
6. PTM briefing readiness  
7. Year-start living syllabus + new joiner bridge  

## Emotional pattern to respect

Confidence collapses when unprepared; resentment peaks with 9 PM notebook stacks; meaning returns with student clarity and parent thanks. Product must reduce evening debt without removing professional craft.
