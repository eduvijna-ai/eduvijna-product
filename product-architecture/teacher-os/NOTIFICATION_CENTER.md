# Notification Center (Wave 2)

**ID:** PA-NOTIFY-001  
**Status:** Planned — Wave 2 (not Wave 1 / EBP-001)  
**Type:** Teacher workflow notifications (not chat)

---

## Recommendation

Introduce a **Notification Center** in **Wave 2** (Teaching Assistant phase), complementary to Today's Mission / Today Dashboard.

Not chat pings.  
**Teacher workflow notifications.**

---

## Examples

| Notification | Meaning |
|--------------|---------|
| ✓ Worksheet ready | Artifact reached AI Generated / Teacher Review |
| ✓ Review pending | Items waiting in Review Queue |
| ✓ Quiz scheduled | Published assessment has a schedule |
| ✓ Homework published | Artifact Published to students |
| ✓ Students submitted | Attempts completed threshold |
| ✓ AI found weak topics | Analyze produced actionable insight |

---

## Product rules

1. Complements Today Dashboard — does **not** replace Mission.  
2. Default quiet: batch / digest friendly; no WhatsApp-style interruption storm.  
3. Every notification deep-links to Work, Artifact, Review Queue, or Analyze action.  
4. Respect Teacher Memory quiet hours if set.  
5. Never auto-publish because a notification fired.  
6. Distinct from ERP/chat messaging channels.

---

## Placement

| Surface | Role |
|---------|------|
| Shell bell | Opens Notification Center |
| Today Dashboard | “Recent / attention” may mirror top items |
| Mission | Counts remain factual; notifications explain *changes* |
