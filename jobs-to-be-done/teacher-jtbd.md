# Teacher Jobs To Be Done

**ID:** JTBD-TEACHER-001  
**Status:** Draft — TLM-001  
**Format:** Trigger → Desired outcome → Current process → Pain → AI opportunity

---

## How to read this document

Each job is a progress the teacher is trying to make in a situation — not a feature request.

Time estimates are **composite field estimates** for an Indian middle-school teacher with ~40 students/section and 4–6 daily periods. They are directional for prioritisation, not laboratory measurements.

---

## Cluster A — Prepare to teach

### JTBD-A1. Prepare tomorrow’s lesson

| Field | Detail |
|-------|--------|
| **Trigger** | End of today / Sunday night; upcoming period on a specific chapter |
| **Desired outcome** | Clear objective, explanation arc, examples, activity, board plan, and materials ready for a 40-minute period |
| **Current process** | Re-read textbook → recall last year → type/handwrite plan → search YouTube/examples → make/print worksheet (optional) → ~90–150 minutes for a careful lesson |
| **Pain** | Repeated manual work; quality depends on fatigue; weak differentiation |
| **AI opportunity** | From intent (grade, subject, chapter, period length, board), draft full lesson kit for teacher review in minutes |

---

### JTBD-A2. Build or refresh teaching materials

| Field | Detail |
|-------|--------|
| **Trigger** | Need worksheet, quiz, flashcards, summary notes, or slides for a topic |
| **Desired outcome** | Board-aligned materials at right difficulty, printable/shareable, with answer key |
| **Current process** | Copy from guides, type MCQs, browse internet, edit heavily — 45–120 minutes per artefact |
| **Pain** | Inconsistent quality; copyright uncertainty; not aligned to exactly what was taught |
| **AI opportunity** | Generate worksheet/assessment/notes/flashcards from chapter + “what I taught this week”; teacher edits |

---

### JTBD-A3. Convert existing content into usable class assets

| Field | Detail |
|-------|--------|
| **Trigger** | Has PDF notes, handwritten notes, previous paper, textbook page photos, YouTube explanation |
| **Desired outcome** | Questions, summary, or lesson support derived from *her* sources |
| **Current process** | Manual retyping / re-creating |
| **Pain** | Feels wasteful; version sprawl across phone gallery and pendrive |
| **AI opportunity** | Ingest document/image/YouTube/website → draft quiz/worksheet/summary |

---

### JTBD-A4. Plan the week / fortnight

| Field | Detail |
|-------|--------|
| **Trigger** | Monday planning or post-holiday restart |
| **Desired outcome** | Topics mapped to available periods with test/revision buffers |
| **Current process** | Spreadsheet or diary; ignore school event calendar until conflict hits |
| **Pain** | Plans die after disruptions |
| **AI opportunity** | Calendar-aware week plan that rebalances when periods are lost |

---

### JTBD-A5. Plan the academic year syllabus

| Field | Detail |
|-------|--------|
| **Trigger** | Session start / new allocation |
| **Desired outcome** | Month-wise coverage with assessment anchors |
| **Current process** | Static yearly planner for submission + private real plan |
| **Pain** | Dual planning (compliance vs reality) |
| **AI opportunity** | Living syllabus plan tied to board curriculum + school calendar |

## Cluster B — Teach & manage the room

### JTBD-B1. Deliver a clear class period

| Field | Detail |
|-------|--------|
| **Trigger** | Bell rings |
| **Desired outcome** | Most students understand the intended concept; class remains orderly |
| **Current process** | Explain → example → questions → practice |
| **Pain** | Mixed ability; interruptions; time shortage |
| **AI opportunity** | Alternate explanations, quick examples, and mid-lesson check questions on demand |

---

### JTBD-B2. Check understanding in the moment

| Field | Detail |
|-------|--------|
| **Trigger** | Mid-lesson uncertainty about whether students “got it” |
| **Desired outcome** | Fast signal of who is lost, without full test logistics |
| **Current process** | Oral questions to same confident students; or skip |
| **Pain** | Silent confusion remains invisible |
| **AI opportunity** | 3–5 question exit checks + instant concept flags |

---

### JTBD-B3. Handle doubts efficiently

| Field | Detail |
|-------|--------|
| **Trigger** | Student asks / looks confused |
| **Desired outcome** | Re-explain at student level without derailing whole class |
| **Current process** | Improvised re-teach; sometimes defer |
| **Pain** | Time; uneven help; teacher knowledge gaps on edge questions |
| **AI opportunity** | Teacher-facing explainer assist (EduAsk-style) + student practice variants after approval |

---

### JTBD-B4. Survive unexpected period loss / substitution

| Field | Detail |
|-------|--------|
| **Trigger** | Cover period, assembly overrun, sudden event |
| **Desired outcome** | Useful learning happens; own syllabus plan updates |
| **Current process** | Improvised worksheet or study hall; replan tonight |
| **Pain** | Cognitive whiplash; wasted days accumulate |
| **AI opportunity** | Instant meaningful filler activities + auto-suggest revised pacing |

---

## Cluster C — Assess & evaluate

### JTBD-C1. Create a fair test / quiz

| Field | Detail |
|-------|--------|
| **Trigger** | Unit test window / weekly check |
| **Desired outcome** | Blueprint-aligned paper with balanced difficulty and answer key |
| **Current process** | Write manually or lightly edit old papers — 1–3 hours |
| **Pain** | Pattern fidelity; parallel-section fairness; typoos under time pressure |
| **AI opportunity** | Generate assessment from taught topics + blueprint; variants for sections |

---

### JTBD-C2. Conduct and collect assessment

| Field | Detail |
|-------|--------|
| **Trigger** | Scheduled test |
| **Desired outcome** | Smooth administration; all scripts accounted for |
| **Current process** | Paper distribution / digital link share; invigilate |
| **Pain** | Absentees; device issues; cheating; logistics |
| **AI opportunity** | Reliable assign/share/attempt flows integrated with class roster |

---

### JTBD-C3. Evaluate answer sheets / notebooks quickly with quality

| Field | Detail |
|-------|--------|
| **Trigger** | Stack of work after class/test |
| **Desired outcome** | Accurate marks + useful feedback before next related lesson |
| **Current process** | Manual correction evenings — often 2–5+ hours per test set |
| **Pain** | Biggest chronic time loss; feedback quality decays |
| **AI opportunity** | Assisted scoring for objective items; draft feedback for short answers; teacher confirms |

---

### JTBD-C4. Turn results into insight

| Field | Detail |
|-------|--------|
| **Trigger** | Marks entered |
| **Desired outcome** | Know which concepts/students need re-teaching this week |
| **Current process** | Mental averages; sometimes Excel |
| **Pain** | Class average hides individuals; action delayed |
| **AI opportunity** | Concept heatmap, weak-student lists, suggested remediation groups |

---

## Cluster D — Homework & practice

### JTBD-D1. Assign the right homework

| Field | Detail |
|-------|--------|
| **Trigger** | End of lesson |
| **Desired outcome** | Practice that reinforces today’s learning without overload |
| **Current process** | Textbook exercise numbers on board / WhatsApp |
| **Pain** | One-size-fits-all; load clashes with other subjects |
| **AI opportunity** | Differentiated practice sets from lesson objectives; teacher approves |

---

### JTBD-D2. Track homework completion meaningfully

| Field | Detail |
|-------|--------|
| **Trigger** | Next day / week review |
| **Desired outcome** | See patterns (chronic skippers vs one-off) and respond |
| **Current process** | Ticks in diary; incomplete memory |
| **Pain** | No longitudinal view; confrontations lack evidence |
| **AI opportunity** | Completion analytics tied to student profile |

## Cluster E — Classroom operations

### JTBD-E1. Take and reconcile attendance

| Field | Detail |
|-------|--------|
| **Trigger** | Homeroom / period start |
| **Desired outcome** | Accurate attendance with minimal time |
| **Current process** | Roll call + register ± ERP re-entry |
| **Pain** | Dual entry; disputes; time theft from teaching |
| **AI opportunity** | Fast roster flows; anomaly flags; no double work (ops + integrity, light AI) |

### JTBD-E2. Manage class teacher pastoral load

| Field | Detail |
|-------|--------|
| **Trigger** | Behaviour, uniform, wellbeing, leave notes |
| **Desired outcome** | Care without losing academic time |
| **Current process** | Memory + diary remarks |
| **Pain** | Invisible emotional labour |

## Cluster F — Communicate

### JTBD-F1. Message parents clearly

| Field | Detail |
|-------|--------|
| **Trigger** | Absence, performance dip, behaviour, logistics |
| **Desired outcome** | Respectful, precise message; appropriate channel; documented |
| **Current process** | Type WhatsApp each time; tone risk |
| **Pain** | After-hours drain; misunderstandings |
| **AI opportunity** | Draft messages from facts in system; multilingual; teacher approves before send |

---

### JTBD-F2. Prepare for PTM

| Field | Detail |
|-------|--------|
| **Trigger** | PTM scheduled |
| **Desired outcome** | Per-student talking points with evidence and one next step |
| **Current process** | Flip marklists night before; rely on memory |
| **Pain** | Uneven preparation; stressful conversations |
| **AI opportunity** | Auto-briefing cards per student from attendance, assessments, homework |

---

### JTBD-F3. Write report remarks

| Field | Detail |
|-------|--------|
| **Trigger** | Report deadline |
| **Desired outcome** | Personal, honest, kind remarks at scale |
| **Current process** | Copy-paste banks + light edits — hours |
| **Pain** | Inauthentic remarks; time crush |
| **AI opportunity** | Evidence-based remark drafts; teacher edits every line |
